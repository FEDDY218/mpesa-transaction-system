# M-Pesa Transaction System

## Project Overview

The M-Pesa Transaction System is a beginner-friendly Python project that simulates basic mobile money transactions. It demonstrates how Object-Oriented Programming (OOP) can be used to represent users and manage transaction-related operations.

## Features

- Store sender details, phone numbers, transaction amounts, and balances.
- Simulate sending money.
- Check account balances.
- Display transaction status.
- Create multiple transaction objects using a Python class.

## Technologies Used

- Python 3

## Object-Oriented Programming Concepts

This project demonstrates the following OOP concepts:

- **Classes and Objects:** Creating transaction objects from the `MpesaTransaction` class.
- **Constructors:** Using `__init__()` to initialize object attributes.
- **Instance Attributes:** Storing transaction and account information.
- **Methods:** Defining functions such as `send_money()`, `check_balance()`, and `transaction_status()`.

## How to Run the Project

1. Install Python 3 if it is not already installed.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   ```bash
   python main.py
   ```

   If your Python file has a different name, replace `main.py` with that filename.

## Learning Objectives

The goal of this project is to practice Python classes, constructors, instance attributes, and methods through a real-world-inspired mobile money scenario.

## Disclaimer

This is an educational simulation. It does not connect to the actual M-Pesa platform, process real payments, or access real customer accounts.
